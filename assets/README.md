# Assets

This directory stores catalog resources and documentation screenshots.

Documentation screenshots:
- `panel.png`: Embedded Codex management panel (MCP Apps), Traditional Chinese, rendered from the built-in `?preview` sample data.
- `settings_en.png`: Windows Forms graphical status and configuration window (English view).
- `settings_zh.png`: Windows Forms graphical status and configuration window (Traditional Chinese view).
- `startup_manager.png`: Standalone Windows Startup Manager control panel (Traditional Chinese view, empty temporary profile).

All four screenshots are produced by `tools/capture_screenshots.ps1` from temporary sample data; rerun it after UI changes.
